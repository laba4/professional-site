# Uses

A list of apps and services I use for my craft

## Apps

### _General_

- [1Password](https://1password.dev/) to store logins and SSH keys
- [Obsidian](https://obsidian.md/) to take notes and organize knowledge
- [VMware Fusion](https://vmware.com/products/desktop-hypervisor/workstation-and-fusion) to run Linux virtual machines

### _Development_

- [Docker](https://docker.com/) to develop apps locally and not clutter the host machine with dependencies
- [TablePlus](https://tableplus.com/) to connect to databases
- [VS Code](https://code.visualstudio.com/) to read and write code

## Services

- [AWS](https://docs.aws.amazon.com/AmazonS3/latest/userguide/WebsiteHosting.html) to develop cloud solutions
- [Cloudflare DNS](https://cloudflare.com/products/dns/) to make services publicly resolvable by hostname
- [Infomaniak](https://infomaniak.com/) to register and manage domains
- [Proton Mail](https://proton.me/mail/) to send and receive emails
- [Tailscale](https://tailscale.com/) to access the homelab remotely
